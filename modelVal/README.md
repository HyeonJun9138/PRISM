# PRISM modelVal — 라이브 검증 콘솔

학습된 예측모델을 **직접 조종하면서** 검증하는 파일럿-인-더-루프 환경.
dataGen의 물리 엔진과 modelTraining의 특징 파이프라인을 **그대로 임포트**해서
쓴다 (bridge/) — 학습 때와 1비트도 다르지 않은 조건으로 모델을 시험한다.

## 실행

```bash
python %PRISM_ROOT%\modelVal\main.py
# 포트 8810 (dataGen 8770 / modelTraining 8790 과 동시 실행 가능)

python main.py smoke   # 헤드리스 자체검증 (~60초, 모델 필요)
```

## 조종 (eVTOL 실물 포락선 그대로 — 물리를 속일 수 없음)

| 키 | 동작 |
|---|---|
| ← → | 선회 (뱅크 25° 한계 내 선회율) |
| ↑ ↓ | 가속 / 감속 |
| Space | 최대 감속 (v_min 30 m/s까지) |
| G / O / P | GT · 관측 · 예측 레이어 토글 |
| 마우스 휠 | 줌 (양쪽 패널 각각) |

## 라이브 채점 (하단 패널)

- **오차@5/10/15초**: 과거에 한 예측을, 시뮬레이션이 그 시점에 도달했을 때
  실현된 GT와 대조 (K갈래 중 최선, 롤링 400점)
- **cov90**: "90%라고 말한 영역"에 실제가 들어간 비율 — 0.90 근처면 초록
- **추론 지연**: 프레임당 전체 트랙 배치 forward 실측 (EMA/최대)
- 시나리오는 150초마다 자동 로테이션 (55 m/s 기체가 느린 트래픽을
  ~2분에 따돌리기 때문)

## 구조

```
main.py            유일한 최상위 파일 (gui / smoke)
bridge/            dataGen·modelTraining sys.path 브리지 (물리·모델 재사용의 핵심)
runtime/session.py 라이브 세션 스레드 (엔진 + 키보드 + 로테이션)
runtime/predictor.py 모델 로드 + 관측→특징→예측→월드좌표 역변환
runtime/scoring.py 예측 링버퍼 + 실현치 대조 채점 (MC-HPD cov90)
console/           stdlib 서버 + Canvas 프런트 (패키지명이 gui가 아닌 이유:
                   bridge가 dataGen을 앞세우면 dataGen의 gui와 충돌)
```
